
# Rexumly

Rexumly is an AI-powered resume analyzer that helps
users evaluate and improve their resumes.

## Features
- Resume PDF upload
- Resume text extraction
- AI-powered resume analysis
- ATS compatibility assessment
- Job description comparison
- Resume improvement suggestions

## Technologies
- HTML5
- CSS3
- JavaScript
- PDF.js
- Google Gemini API
- Vercel
